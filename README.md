# Prashast Vats: portfolio

The source of [prashastvats1.github.io](https://prashastvats1.github.io): a fantasy-themed
portfolio (spellbook home, character record, hall of artifacts, wizard's laboratory, archive of
notes, guild recruitment) built as a static React app on GitHub Pages. `DESIGN.md` is the design
specification; `PHASE_*.md` record how each part was built and verified.

## Local setup

Requires Node 20 (the version the deploy workflow uses) and npm.

```bash
npm install
npm start            # dev server on http://localhost:3000
CI=true npm test -- --watchAll=false   # full test suite, once
npm run build        # production build in build/
```

`npm start`, `npm test`, and `npm run build` first run `scripts/prepare-assets.js`, which copies
the web-ready avatar files from `avatar/` into `public/avatar/` and writes
`src/generated/assetManifest.js`. Both outputs are gitignored.

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`: `npm install`, `npm run build`, then
upload of `build/` to GitHub Pages. This workflow is the only deployment path: there is no
`npm run deploy` script, and nothing is published from a local machine or a `gh-pages` branch.
Work on other branches is released by merging it into `main`. The site is served from
the domain root, and routes are hash-based (`/#/projects/remora`), so no server rewrites are
needed.

## Architecture

| Area | Where |
| --- | --- |
| Routing | `src/router/` (a small hash router; no routing library), routes in `src/navigation.js` and `src/App.js` |
| Shared shell | `src/components/fantasy/` (navigation, frame, avatar, buttons, sound control) |
| Page transitions | `src/transition/` (honours `prefers-reduced-motion`) |
| Pages | `src/pages/<page>/` |
| Contact details | `src/config.js` |
| Project data | `src/pages/projects/artifacts.js`: the single source for the Hall, Home previews, and Hire proof |
| Resume data | `src/pages/resume/resumeContent.js`, transcribed from `public/Prashast_Vats_Resume.pdf` |
| Blog posts | `src/blog/posts/` |
| Styles | `src/index.css` (hand-written; Tailwind supplies only its base reset) |
| Ambient sound | `src/audio/AudioProvider.js`, above the router so playback survives navigation |

### Assets

- Artwork lives in `public/assets/`. Components check the generated asset manifest before
  rendering an image, so a missing file shows a designed fallback instead of a broken image.
- Responsive WebP variants (`<name>-<width>.webp`) are committed. After replacing a source image,
  regenerate them with `python3 scripts/make-image-variants.py` (needs Pillow).
- `avatar/` holds the owner's original avatar files. Only the WebP versions are published.
- `public/social-preview.jpg` is the link-preview image (`python3 scripts/make-social-preview.py`).
- `public/assets/audio/ambient.mp3` ("Lanternlight Lane") is an original loop generated by
  `scripts/generate-ambient.py`. The script writes out the melody, chords, and arrangement and
  synthesizes every instrument in Python (standard library only); FFmpeg (with `libmp3lame`)
  then adds the room reverb, sets the loudness, and encodes the MP3. It uses no recordings,
  samples or third-party material. Re-run it with `python3 scripts/generate-ambient.py`. The
  site tries once to start it when a visitor opens the portfolio. Browsers such as Chrome and
  Brave refuse audible playback until the visitor interacts with the page, so it then starts on
  the visitor's first click or key press (one further attempt only). The sound control invites
  a press meanwhile.
- `resume/Prashast_Vats_Resume.docx` is the editable source of the published PDF. It is kept out
  of `public/` so it is not deployed.

## AI tool configuration

Three instruments in the Wizard's Laboratory call a separate Cloudflare Worker (`worker/`; see
`worker/README.md`), which holds the OpenAI key server-side. The site itself needs only one
public build variable:

| Name | Where | Secret? |
| --- | --- | --- |
| `REACT_APP_AI_API_URL` | GitHub repository variable `AI_API_URL`, passed in by the deploy workflow; `.env.local` for local runs | No: it is a public address |

Never put an API key or any other secret in a `REACT_APP_` variable: Create React App copies
those into the public JavaScript bundle. Without `REACT_APP_AI_API_URL`, the AI instruments
explain that they are not connected and send nothing; the rest of the site works normally. The four other instruments run
entirely in the browser.
